# template-skill

Base neutra e reutilizável para testes de skill de estilização: Vite + React + TypeScript + Tailwind CSS + shadcn/ui + Framer Motion, sem nenhuma customização visual.

## Versões travadas nesta base
- tailwindcss: 4.3.3
- @tailwindcss/vite: 4.3.3
- framer-motion: 13.1.1
- shadcn/ui CLI: 4.19.0 (primitivos: Base UI)
